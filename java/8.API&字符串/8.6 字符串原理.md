  直接赋值会复用字符串常量池中的
  `new`出来不会复用，而是开辟一个新的空间

**底层原理2：== 号比较的到底是什么**
  **基本数据类型比较数据值**
    `byte short int long float double char boolean`
  **引用数据类型比较地址值**
    类（如`String`，`Integer`，自定义类） 接口（如`List`，`Runnable`） 数组（`int[]`，`String[]`） 枚举（`enum`）

**底层原理3：字符串拼接的底层原理**
  **+运算符拼接**
    a.编译期常量拼接：直接合并为常量
    b.运行时变量拼接：自动转为`StringBuilder`的`append`操作
    c.循环中使用+的问题：会导致编译器优化失效
  **`StringBuilder`拼接**
    a.内部存储：维护一个 `char[] value` 数组（默认容量16，用于存储字符
    b.`append`操作：直接将新字符写入 `value` 数组，若数组容量不足则触发扩容
    c.扩容逻辑：
        计算新容量：`newCapacity = oldCapacity * 2 + 2`（确保足够容纳新内容）
        创建新的 `char[]` 数组，将原数组内容复制到新数组，替换旧数组
    d.`toString()`：最终通过 `new String(value, 0, count)` 创建不可变的 `String` 对象（不复制整个数组，仅使用有效长度）
  **`StringJoiner`拼接**
    a.内部维护一个`StringBuilder`对象，用于实际拼接
    b.初始化时指定分隔符，前缀，后缀，`add`方法本质调用`StringBuilder.append`
    c.最终通过`toString()`输出拼接结果
