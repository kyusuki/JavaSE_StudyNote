```
                        IO流体系
                           |
              ----------------------------
             |                            |
           字节流                        字符流
             |                            |
       -------------                -------------
      |             |              |             |
 InputStream   OutputStream      Reader        Writer            <-抽象类
 （字节输入流）  （字节输出流）   （字符输入流）  （字符输出流）

抽象类无法创建对象，所以InputStream、OutputStream、Reader、Writer只能通过其子类创建对象
```

### 一、InputStream/OutputStream（常见子类结构）
```
                                 InputStream
                                      |
            -----------------------------------------------------
           |                          |                          |
    FileInputStream           ObjectInputStream         BufferedInputStream
    （操作本地文件）               （操作对象）                （带有缓冲区）
```
```
                                 OutputStream
                                      |
            -----------------------------------------------------
           |                          |                          |
    FileOutputStream         ObjectOutputStream        BufferedOutputStream
    （操作本地文件）               （操作对象）                （带有缓冲区）
```
