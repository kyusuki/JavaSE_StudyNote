==print()==：基础输出，不自动换行
```
System.out.print("Hello");
System.out.print(" World");
```
  

==println()==：输出后自动换行
```
System.out.println("Hello");
System.out.println("world");
```


==printf()==：格式化输出，支持占位符
%d:整数 %s:字符串 %f:浮点数 %c:字符
```
String name="张三";
int age=20;
double score=95.5;
System.out.printf("姓名：%s，年龄：%d，成绩：%.1f",name,age,score);
```
