### 一、包装类：基本数据类型对应的引用类型

| 基本数据类型  | 包装类       |
| ------- | --------- |
| byte    | Byte      |
| short   | Short     |
| int     | Integrer  |
| long    | Long      |
| float   | Float     |
| double  | Double    |
| char    | Character |
| boolean | Boolean   |

### 二、针对int类型的包装类创建对象方式
```
JDK5以前的方式
构造方法
public Integer(int value)                         根据传递的整数创建Integer对象
public Integer(String s)                          根据传递的字符串创建Integer对象

静态方法
public static Integer valueOf(int i)              根据传递的整数创建Integer对象
public static Integer valueOf(String s)           根据传递的字符串创建Integer对象
public static Integer valueOf(String s,int radix) 根据传递的字符串和进制创建Integer对象

构造方法与静态方法的区别
构造方法：每次调用都会强制创建一个新的对象
静态方法：在-128到127的范围内会优先使用缓存中的对象，就是复用。超出范围则会创建新的对象
```

### 三、包装类的计算方法
```
自动拆箱与自动装箱（就相当于是没有了int和Integer的区别，两者之间可以直接计算）
Integer i=10; //自动装箱，等价于Integer i=Integer.valueOf(10);
int j=i; //自动拆箱，等价于int j=i.intValue();

其次，有了自动装箱与自动拆箱，JDK5之前创建Integer对象的方法也不再使用
```

### 四、Integer成员方法
```
public static String toBinaryString(int i)        得到二进制
public static String toOctalSting(int i)          得到八进制
public static String toHexString(int i)           得到十六进制

public static int parseInt(String s)              将字符串类型的整数转成int类型的整数
注：八种包装类中，除了Character都有对应的parseXxx方法

弊端由此诞生：
在之前使用next、nextInt、nextDouble接收键盘录入数据的时候，遇到空格、回车、制表符就会立即停止。所以，在以后要接收一整行数据时，用nextLine
```
