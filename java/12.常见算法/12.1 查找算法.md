## 一、基本查找（顺序查找）
  **核心思想**
   遍历数组，逐个比较元素与目标值，找到则返回存在，否则返回不存在
   使用于无序数组或数据量小的场景
  **关键代码**
```
    public static boolean basicSearch(int[] arr,int target){
        for(int i=0;i<arr.length;i++){
            if(arr[i]==target){ //逐个比对
                return true;
            }
        }
        return false; //遍历完未找到
    }
```
  **特点**
   时间复杂度：O (n)（线性时间）
   无需排序，实现简单
   数据量越大，效率越低

## 二、二分查找（折半查找）
  **核心思想**
   针对有序数组，通过不断将查找范围折半缩小，快速定位目标值
   每次比较中间元素，缩小一半查找范围
  **关键代码**
```
    public static int binarySearch(int[] arr,int target){
        int min=0;
        int max=arr.length-1;
        while(min<=max){
            int mid=(max-min)/2+min; //计算中间索引（避免溢出）
            if(target<arr[mid]){
                max=mid-1; //目标在左半部分
            }
            else if(target>arr[mid]){
                min=mid+1; //目标在右半部分
            }
            else{
                return mid; //找到目标，返回索引
            }
        }
        return -1; //未找到
    }
```
  **特点**
   时间复杂度：O (log₂n)（线性时间）
   必须作用于有序数组
   数据量越大，相比顺序查找优势越明显

## 三、插值查找
  **核心思想**
   是二分查找的优化版，针对均匀分布的有序数组
   中间索引计算更贴切目标值可能的位置（类似字典查找逻辑）
  **关键代码**
```
    public static int interpolationSearch(int[] arr,int target){
        int min=0;
        int max=arr.length-1;
        while(min<=max){
            //核心：根据目标值与边界值的比例计算中间索引
            int mid=min+((target-arr[min])*(max-min))/(arr[max]-arr[min]);
            if(target<arr[mid]){
                max=mid-1; //目标小于中间值，既目标在左侧，把max指向mid-1
            }
            else if(target>arr[mid]){
                min=mid+1; //目标大于中间值，既目标在右侧，把min指向mid+1
            }
            else{
                return mid; //找到目标
            }
        }
        return -1;
    }
```
  **特点**
   时间复杂度：平均O (log log n)，最坏O (n)
   适用于均匀分布的有序数组
   分布不均匀时性能可能不如二分查找

## 四、分块查找（块查找）
  **核心思想**
   结合顺序查找和二分查找的优势，分两步查找：
    1.将数组分成若干块
    2.先确定目标所在的块，再在块内顺序查找
  **关键代码**
   1.块结构定义
```
    class Block{
        private int max; //块内最大值
        private int startIndex; //块起始索引
        private int endIndex; //块结束索引
    }
```
   2.查找实现
```
    //确定目标所在块
    public static int getBlockIndex(Block[] blockArr,int target){
        for(int i=0;i<blockArr.length;i++){
            if(target<=blockArr[i].getMax()){
                return i;
            }
        }
        return -1;
    }
    //在块内查找目标
    public static int getIndex(Block[] blockArr,int[] arr,int target){
        int blockIndex=getBlockIndex(blockArr,target)
        if(blockIndex==-1){
            return -1;
        }
        for(int i=blockArr[blockIndex].getStartIndex();i<=blockArr[blockIndex].getEndIndex;i++){
            if(arr[i]==target){
                return i;
            }
        }
        return -1;
    }
```
  **特点**
   时间复杂度：取决于块的大小，一般介于O (n)和O (log₂n)之间
   无需整体排序，需块间有序
   适合数据量较大且需要频繁插入删除的场景
