### 一、ASCII字符集
  1. 计算机存储规则（英文）
    `ASCII`编码规则：补齐8位，不足前面补0
    `ASCII`解码规则：直接转成十进制
```
a --(查询ASCII)--> 97(1100001) --(编码)--> 01100001

01100001 --(解码)--> 97 --(查询ASCII)--> a
```
  2. 计算机存储规则（中文）
    a. `GB2312`字符集
    b. `BIG5`字符集
    c. `GBK`字符集
    d. `Unicode`字符集

### 二、GBK字符集
  1. 汉字使用两个字节存储
  2. 中文中高位字节二进制一定以1开头，转成十进制之后是一个负数
  3. 英文使用一个字节存储，兼容`ASCII`，二进制前用0补齐8位
  
### 三、Unicode字符集
  1. 计算机存储规则
```
a --(查询Unicode)--> 97 --(编码)--> UTF-16编码/UTF-32编码/UTF-8编码

UTF-16编码规则：用2~4个字节保存
UTF-32编码规则：固定使用四个字节保存
UTF-8编码规则：用1~4个字节保存


```
  2. `UTF-8`编码方式（二进制）
    `0xxxxxxx` （`ASCII`码）
    `110xxxxx 10xxxxxx`
    `1110xxxx 10xxxxxx 10xxxxxx`
    `11110xxx 10xxxxxx 10xxxxxx 10xxxxxx`

### 四、编码中出现乱码
  1. 读取数据时未读完整个汉字
  2. 编码和解码时的方式不统一 

### 五、编码与解码
  1. 编码的方法
    ```
    public byte[] getBytes()                       使用默认方法进行编码
    public byte[] getBytes(String charsetName)     使用指定方式进行编码
    ```
  2. 解码的方法
    ```
    String(byte[] bytes)                           使用默认方法进行编码
    String(byte[] bytes,String charsetName)        使用指定方法进行编码
    ```
