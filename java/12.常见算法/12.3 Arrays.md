操作数组的工具类（无需创建对象，直接类名调用方法）
```
public static String toString(arr)                          把数组拼接成一个字符串
public static int binarySearch(arr,target)                  二分查找法查找元素
public static int[] copyOf(oldArr,newArrLength)             拷贝数组
public static int[] copyOfRange(oldArr,startIndex,endIndex) 拷贝数组（指定范围）
public static void fill(arr,target)                         填充数组
public static void sort(arr)                                按照默认方式进行数组排序
public static void sort(arr,sortMethod)                     按照指定的规则排序
```
