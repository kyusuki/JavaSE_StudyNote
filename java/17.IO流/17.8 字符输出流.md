### 一、FileWrite构造方法
  1. 构造方法
```
public FileWrite(File file)                       创建字符输出流关联本地文件
public FileWrite(String pathname)                 创建字符输出流关联本地文件
public FileWrite(File file,boolean append)        创建关联本地文件，续写
public FileWrite(String pathname,boolean append)  创建关联本地文件，续写
```
  2. 成员方法
  ```
void write(int c)                             写出一个字符
void write(String str)                        写出一个字符串
void write(String str,int off,int len)        写出一个字符串的一部分
void write(char[] cbuf)                       写出一个字符数组
void write(char[] cbuf,int off,int len)       写出字符数组的一部分
  ```

### 二、FileWrite细节
  1. 创建字符输出流对象
    a：参数是字符串表示的路径或者File对象都是可以的
    b：若文件不存在会创建一个新的文件，但是要保证父级路径是存在的
    c：若文件已经存在，则会清空文件，若不想清空可以打开续写开关
  2. 写数据
    如果write方法的参数是整数，但是实际上写到本地文件中的是整数在字符集上对应的字符
  3. 释放资源
    每次使用完流之后都要释放资源
