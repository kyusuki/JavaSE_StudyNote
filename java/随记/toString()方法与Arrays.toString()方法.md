### 一、区别所在

|      | toString()        | Arrays.toString()   |
| ---- | ----------------- | ------------------- |
| 定义位置 | Object类中定义（所有类继承） | Arrays工具类中的静态方法     |
| 调用方法 | 对象.toString()     | Arrays.toString(数组) |
| 作用范围 | 所有引用数据类型（包括数组）    | 只适用于数组              |


### 二、适用场景

|            | toString()         | Arrays.toString() |
| ---------- | ------------------ | ----------------- |
| 对数组的作用     | 返回数组对象的地址值（哈希码）    | 返回数组内容的字符串表示      |
| 对自定义类作用    | 默认返回地址值，重写后返回自定义内容 | 不适用               |
| 对集合类作用     | 重写后返回集合内容的字符串表示    | 不适用               |
| 对String类作用 | 返回字符串本身（返回this）    | 不适用               |
| 对基本数据类型    | 不直接适用（需要通过其包装类实现）  | 适用于基本类型数组         |
| 对包装类       | 适用且已重写，返回原数据值      | 不适用               |
