例（在一个工具类中）：
    `private String status="正常";`
    `public void setXXX(String newStatus){`
        `List<String> allowedList=Arrays.asList("正常","冻结");`
        `if(allowedlist.contains(newStatus){`
            `this.status=newStatus;`
            `System.out.println("状态更新成功");`
        `}`
        `else{`
            `System.out.println("状态更新失败");`
        `}`
    `}`
    `public String getXXX(){`
        `return status;`
    `}`
    逻辑就是先默认一个初始状态，再创建一个列表存放固定几个状态，通过检验新输入的状态是否在列表中，存在就覆盖旧`status`，以此做到状态更新。
    可不可以用`ArrayList`的`add()`呢？答案是可以，比如
    `ArrayList<String> XXXList=new ArrayList<>();`
    `XXXList.add("正常");`
    `XXXList.add("冻结");`
    但问题是，`ArrayList`是动态集合，会自动扩容，无法满足可选值固定要求。
