### 一、特点
  有序：存和取的元素顺序一致
  有索引：可以通过索引操作元素
  可重复：存储的元素可以重复

### 二、List方法
```
基本方法
Collection的方法都被List继承
List集合有索引，有更多索引操作
特有基本方法
void add(int index,E element)             在此集合中的指定位置插入指定元素
E remove(int index)                       删除指定索引处的元素，返回被删除的元素
E set(int index,E element)                修改指定索引处的元素，返回被修改的元素
E get(int index)                          返回指定索引处的元素
```
```
特有遍历方法：列表迭代器
获取列表迭代器对象
ListIterator<E> listIterator()            返回列表迭代器对象，默认指向0索引
特有常用方法（此接口继承于Iterator）
public void add(E e)                      将指定元素插入到列表中
public boolean hasPrevious()              逆向遍历列表，同正向判断一样，有则返回true，反之返回false
public E previous()                       返回列表前一个元素

五种遍历方式对比
迭代器遍历        在遍历的过程中需要删除元素
列表迭代器        在遍历的过程中需要添加元素
增强for遍历       仅仅只需遍历
Lambda表达式     仅仅只需遍历
普通for          遍历时想操作索引
```
