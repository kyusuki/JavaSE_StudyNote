## 一、冒泡排序
  **核心思想**
   重复遍历待排序数组，每次比较相邻两个元素，将较大元素逐步“冒泡”到数组末尾
   每一轮遍历后，未排序部分的最大元素会移动到对应位置，遍历此数逐步减少
  **关键代码**
```
    public static int[] bubbleSort(int[] arr){
        //外层循环控制遍历轮数
        for(int i=0;i<arr.length-1;i++){
            //内层循环比较相邻元素，已排序的末尾元素无需再比较
            for(int j=0;j<arr.length-i-1;j++){
                if(arr[j]>arr[j+1]){
                    //大元素后移
                    int temp=arr[j];
                    arr[j]=arr[j+1];
                    arr[j+1]=temp;
                }
            }
        }
        return arr;
    }
```
  **特点**
   时间复杂度：O (n²)（最坏/平均），O (n)（最优，数组已有序）
   空间复杂度：O (1)，原地排序
   稳定性：稳定
   实现简单，适合小数据场景

## 二、选择排序
  **核心思想**
   每一轮从待排序部分找到最小（或最大）元素，与待排序部分的起始位置交换
   做不缩小待排序范围，直到整个数组有序
  **关键代码**
```
    public static int[] selectionSort(int[] arr){
        //外层循环控制待排序起始位置
        for(int i=0;i<arr.length;i++){
            //内层循环查找待排序部分的最小元素
            for(int j=i+1;i<arr.length;j++){
                if(arr[j]<arr[i]){
                    //交换最小元素与当前起始位置元素
                    int temp=arr[j];
                    arr[j]=arr[i];
                    arr[i]=temp;
                }
            }
        }
        return arr;
    }
```
  **特点**
   时间复杂度：O (n²)（最坏/平均/最优），不受数组初始状态影响
   空间复杂度：O (1)
   稳定性：不稳定（可能交换相等元素的相对位置）
   交换次数少，适合数据移动成本较高的场景

## 三、插入排序
  **核心思想**
   将数组分为“已排序部分”和“未排序部分”
   一次取出未排序部分的元素，插入到已排序部分的合适位置，保持已排序部分有序
  **关键代码**
```
    public static int[] insertionSort(int[] arr){
        //找到未排序部分的起始索引
        int startIndex=0;
        for(int i=0;i<arr.length;i++){
            if(arr[i]>arr[i+1]){
                startIndex=i+1;
                break;
            }
        }
        //遍历未排序部分元素
        for(int i=startIndex;i<arr.length;i++){
            int j=i;
            //向前查找插入位置，同时移动元素
            while(j>0&&arr[j]<arr[j-1]){
                //当移动元素大于前一个元素时停止，小于则交换前移
                int temp=arr[j];
                arr[j]=arr[j-1];
                arr[j-1]=temp;
                j--;
            }
        }
        return arr;
    }
```
  **特点**
   时间复杂度：O (n²)（最坏/平均），O (n)（最优，数组已有序）
   空间复杂度：O (1)
   稳定性：稳定
   适合部分有序或小数据量数组，实际应用中性能优于冒泡排序和选择排序

## 四、快速排序
  **核心思想**
   采用“分治+递归”策略，通过基准数将数组分割为两个部分
   左部分元素均小于基准数，右部分元素均大于基准数，再对两部分分别递归排序
  **递归思想解释**
   1.递归的核心是“将大问题拆解为小问题”：把原始数组排序问题，拆解为“基准数左边子数组排序”和“基准数右边子数组排序”
   2.递归终止条件：当子数组的起始索引大于等于结束索引时（子数组位空或只有一个元素，天然有序）
   3.递归执行逻辑：先完成当前数组的基准数定位，再递归处理左右子数组，最终所有子数组有序后，原始数组有序
  **关键代码**
```
    public static void quickSort(int[] arr,int left,int right){
        int start=left; //左指针（从左向右找到大于基准数的元素）
        int end=right; //右指针（从右向左找到小于基准数的元素）
        int pivot=arr[left]; //选取数组左端点为基准数
        //递归终止条件：子数组五元素或只有一个元素
        if(start>end){
            return;
        }
        //一轮遍历：将数组按基准数分割
        while(start!=end){
            //右指针左移，找到第一个小于基准数的元素
            while(arr[end]>=pivot&&start<end){
                end--;
            }
            //左指针右移，找到第一个大于基准数的元素
            while(arr[start]<=pivot&&start<end){
                start++;
            }
            //交换左右指针指向的元素
            int temp=arr[start];
            arr[start]=arr[end];
            arr[end]=temp;
        }
        //基准数归为：将基准数放到左右指针相遇的位置
        arr[left]=arr[start];
        arr[start]=pivot;
        //递归处理基准数左边的子数组
        quickSort(arr,left,start-1);
        //递归处理基准数右边的子数组
        quickSort(arr,start+1,right);
    }
    
    注意：右指针左移和左指针右移的行为**有严格的先后顺序**，必须先移动右指针，再移动左指针
```
  **特点**
   时间复杂度：O (n log n)（平均/最优），O (n²)（最坏，数组已有序且选端点为基准）
   空间复杂度：O (log n)（递归调用栈开销）
   稳定性：不稳定
   实际应用中效率最高的排序算法之一，适合大数据量场景
