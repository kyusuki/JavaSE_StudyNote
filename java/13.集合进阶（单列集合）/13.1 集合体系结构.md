整体上分为两类：`Collection`（单列集合）   `Map`（双列集合）

```
单列集合体系
                                Collection                          （接口）
                                    |
                       --------------------------
                      |                          |
                     List                       Set                 （接口）
                      |                          |
        -------------------------           ----------- 
       |              |          |         |           | 
    ArrayList    LinkedList    Vector    HashSet    TreeSet         （实现类）
                                           |
                                      LinkedHashSet                 （实现类）


List系列集合：添加的元素是有序（存取有序）、可重复（存储元素可重复）、有索引（可根据索引获取集合中元素信息）
Set系列集合：添加的元素是无序（存取无序）、不重复（集合中不能存储重复的元素）、无索引（无法通过索引获取集合中元素信息）
```
