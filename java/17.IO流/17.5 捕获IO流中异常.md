### 一、try...catch异常处理
  1. 基本做法（手动释放资源）
```
try{
    可能出现异常的代码;
}catch(异常类名 变量名){
    异常的处理代码;
}finally{
    执行所有资源释放操作;
}
```
  2. `jdk7`方案（资源用完最终自动释放）
```
try(创建流对象1;创建流对象2){
    可能出现异常的代码;
}catch(异常类名 变量名){
    异常的处理代码;
}
```
  3. `jdk9`方案（资源用完最终自动释放）
```
创建流对象1;
创建流对象2;
try(流1;流2){
    可能出现异常的代码;
}catch(异常类名 变量名){
    异常的处理代码;
}
```
