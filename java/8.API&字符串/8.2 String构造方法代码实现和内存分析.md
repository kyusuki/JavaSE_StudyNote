### 一、**创建String对象的两种方式**
  1. 直接赋值  `String str="你好Java";`
  2. `new`关键字  如下

| 构造方法                             | 说明               |
| -------------------------------- | ---------------- |
| `public String()`                | 创建空白字符串，不含任何内容   |
| `public String(String original)` | 根据传入的字符串，创建字符串对象 |
| `public String(char[] chs)`      | 根据字符数组，创建字符串对象   |
| `public String(byte[] chs)`      | 根据字节数组，创建字符串对象   |
