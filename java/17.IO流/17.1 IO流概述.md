### 一、IO流与File对文件的处理
  File：表示系统中的文件或者文件夹的路径。但File类只能对文件本身进行操作，不能读写文件里面存储的数据
  IO流：用于==读（input）写（output）==文件中的数据（可以读写文件，或网络中的数据...）

### 二、IO流的分类
```
1.按流的方向                                2.按操作文件类型
           IO流                                      IO流
            |                                         |
      -------------                              -----------
     |             |                            |           |
输入流（读取）  输出流（写入）                    字节流      字符流
                                           字节流可以处理所有类型的文件
                                           字符流只能处理纯文本文件
```
