### 一、概念
  `Object`是`Java`中的顶级父类，所有的类都直接或间接的继承于`Object`类
  `Object`类中的方法可以被所有子类访问

### 二、常见的成员方法
  1. `toString()`：一般会重写，在打印对象时会打印其属性值
```
    比如说有一个User类，在Test类中创建User对象并打印的时候，输出结果为一串地址值。原因是打印时会默认调用Object中的toString()方法，这里面的方法返回的就是地址值。
    所以需要重写tostring()，在User类中重写该方法，保证打印对象时输出的就是属性值
```
  2. `equals()`：比较对象时会重写，比较对象属性值是否相同
```
    equals()方法也是一样的，默认使用Object中的equals()方法，此时比较的就是地址值是否相同
    所以也需要重写equals()方法
```
  3. `clone()`：默认为浅克隆，需要深克隆则需要重写方法或使用第三方工具
    a.==浅克隆==（`Object`中的`clone`方法就是浅克隆）![[Pasted image 20251108170014.png]]
    b.==深克隆==（重写`clone`方法）![[Pasted image 20251108170043.png]]
```
@Override
protected Object clone() throws CloneNotSupportedException{
    int[] date=this.date;
    int[] newDate=new int[date.length];
    for(int i=0;i<date.length;i++){
        newDate[i]=date[i];
    }
    //调用父类中的方法克隆对象
    User u=(User)super.clone(); //强转
    //因为父类中的克隆方法是浅克隆，需要替换克隆出来对象中的数组地址值
    u.date=newDate;
    return u;
}
```



### 三、Objects是一个工具类
```
boolean equals(Object a,Object b)    先做非空判断，比较两个对象
boolean isNull(Object obj)           判断对象是否为null，为null返回true
boolean nonNull(Object obj)          判断对象是否为null，和isNull结果相反
```
