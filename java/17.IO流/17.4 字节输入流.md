### 一、InputStream（常见子类结构）
```
                                 InputStream
                                      |
            -----------------------------------------------------
           |                          |                          |
    FileInputStream           ObjectInputStream         BufferedInputStream
    （操作本地文件）               （操作对象）                （带有缓冲区）
```

### 二、FileInputStream
  操作本地文件的字节输入流，可以把本地文件中的数据读取到程序中来
  步骤：
    1.创建字节输入流对象
       如果文件不存在，就直接报错
         输入流：不存在，直接报错（因为创建出来的文件没有数据，读取就没有意义）
         输出流：不存在，创建一个新的
    2.读入数据
       a.一次读一个字节，读出来的为数据在ASCII码中对应的数字
       b.读到文件末尾时，read方法返回-1
    3.释放资源
       每次使用完流必须释放资源，避免占用

### 三、FileInputStream循环读取
```
FileInputStream fis=new FileInputStream("...");
int b;
while((b=fis.read())!=-1){
    ...
}
fis.close();
```

### 四、FileInputStream一次读取多个字节
```
public int read()                 一次读一个字节数据
public int read(byte[] buffer)    一次度一个字节数组数据，返回值为读了几个

注意：一次读一个字节数组的数据时，每次读取会尽可能把数组装满
```
