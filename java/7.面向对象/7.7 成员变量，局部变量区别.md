### 三、成员变量与局部变量的区别

| 区别     | 成员变量                  | 局部变量                    |
| ------ | --------------------- | ----------------------- |
| 类中位置不同 | 类中，方法外                | 方法内，方法申明上               |
| 初始化值不同 | 有默认初始值                | 没有，使用之前需要完成赋值           |
| 内存位置不同 | 堆内存                   | 栈内存                     |
| 生命周期不同 | 随着对象的创建而存在，随着对象的消失而消失 | 随着方法的调用而存在，随着方法的运行结束而消失 |
| 作用域    | 整个类中有效                | 当前方法有效                  |
