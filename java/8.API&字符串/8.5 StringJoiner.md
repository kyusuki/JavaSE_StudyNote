### 一、**概述**
  `StringJoiner`和`StringBuilder`一样，也可以看成一个容器，创建之后里面的内容是可变的

### 二、**作用**
  提高字符串的操作效率


### 三、**StringJoiner的构造方法**
```
public StringJoiner(Delimiter)                               创建一个StringJoiner对象，指定拼接时的间隔符号
public StringJoiner(Delimiter,startDelimiter,endDelimiter)   创建一个StringJoiner对象，指定拼接时的间隔符号，开始符号，结束符号
```
  
### 四、**StringJoiner的成员方法**
```
public StringJoiner(addDate)      添加数据，并返回对象本身
public int length()               返回长度（字符出现的个数
public String toString()          返回一个字符串（该字符串就是拼接之后的结果）
```
